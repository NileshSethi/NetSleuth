## 3. Discrepancies Found in the Codebase During Audit

The following technical notes were verified during codebase inspection (preserved in codebase per Hard Rule 1):
1. **Timestamp Type in Direct Evaluation:** `evaluation.py` expects pre-parsed datetime timestamps. Passing raw synthetic DataFrames directly without running through `loader.load_flows` causes a TypeError during timedelta addition. (Functions correctly in `app.py` because `load_flows` is invoked first).
2. **Scenario 3 Severity vs. Volume Score:** Scenario 3 exfiltrates 2,400,000 bytes ($2.4\text{ MB}$), which falls into the moderate exfiltration tier ($500\text{ KB} \le \text{bytes} < 5\text{ MB}$, +10 pts). The resulting score is $50 + 10 = 60$ (High), not 80 (Critical). The report correctly documents this score as 60 (High).
3. **Outbound Benign Flows:** Benign web and email traffic in the synthetic generator has `direction == "OUTBOUND"`, but individual flow byte counts stay well below the 500 KB threshold (max 15,000 bytes), correctly preventing false positives.
4. **Host Scan Target Representation:** Host scan alerts set the target field to a string describing multiple hosts (e.g., `"12 hosts (port 445)"`), which `incidents.py` properly filters when enumerating distinct single-host target IP addresses.
